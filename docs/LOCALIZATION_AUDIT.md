# Inspect for EllesmereUI 本地化与物品引用检查

检查范围：设置、观察侧栏、装备推荐、宝石、附魔、制造业品质、套装来源和万奥宝典符文。基于当前源码及内置 GearData，数据标记为赛季 18 / 12.1.0。

## 语言覆盖

| 客户端语言 | 插件设置与推荐文字 | 游戏物品名称 |
| --- | --- | --- |
| enUS | 完整英文基础表 | 从客户端按 ID 获取 |
| zhCN / zhTW | 简体、繁体译文，缺键继承英文基础表 | 从客户端按 ID 获取 |
| ruRU | 保留 15 个设置译文，其余使用英文 | 从客户端按 ID 获取 |
| deDE / frFR / esES / esMX / koKR / itIT / ptBR | 插件自行编写的文字使用英文回退 | 从客户端按 ID 获取 |

设置基础表包含 22 个明确的文本键。鼠标提示中的专精功能及对应设置已移除。BIS、TOP1–TOP3、N/R 是用户要求的统一英文短标记，各语言保持一致。插件显示名称也统一保持 Inspect for EllesmereUI。

## 装备与附魔引用

- 80 组专精/玩法推荐中，3,632 条装备推荐、160 条宝石推荐均有物品 ID；650 个部位附魔推荐同时具有附魔物品 ID 和装备链接内的附魔效果 ID。
- 1,646 条消耗品推荐都有物品 ID；采集数据的 effect 字段主要是英文。显示时优先按物品 ID 获取客户端名称，不直接用这些英文效果名替代已验证物品。
- 排名使用物品 ID；附魔匹配使用 enchantID。翻译不参与判断。制造业品质通过客户端物品信息读取，不按名称判断。
- 已装备物品保留完整实例链接，包含实际附魔、宝石和其他实例信息。推荐库的普通物品链接仅用于推荐展示。
- 名称未缓存时，显示本地化的“正在加载物品 #ID…”；请求仍按当前面板会话合并，物品数据事件驱动刷新。
- 518 条来源记录中，318 条地下城/团队副本记录具有地下城手册 ID，优先使用客户端本地化名称；71 条制造业和 129 条套装来源使用本地化分类文字。

这些统计验证了引用结构完整，不等于逐个在当前游戏客户端确认每个 ID 的名称、赛季归属及推荐正确性。

## 本次修复

1. 新增共享英文设置基础表，首先加载，再叠加各语言译文；补齐简体、繁体“其他界面”标签。
2. 统一装备、宝石、附魔、美化组合和消耗品名称的加载提示，避免未缓存时混入采集数据里的英文名称；组合去重按物品 ID 判断。
3. 修复推荐装备悬浮提示的 Lua 多返回值截断，恢复原生物品链接提示。
4. 新增本地化的职业套装来源标签。万奥宝典名称优先使用现有映射表中的客户端 trait spellID，再回退原始 spellID。
5. 移除属性统计模块的四语言白名单；统计名称使用客户端的 ITEM_MOD / STAT 文本。
6. 更新缺少推荐数据的提示，说明需要重装包含 GearData 的完整插件。

运行文件：新增 locales/enUS.lua；修改 locales/locales.xml、三个已有语言文件、Options.lua、InspectUnitStats.lua，以及 RecommendationCompat/Core/Locale/Gear/Consumables/Panel.lua。TOC 本身无变化，新增文件由已有 locales.xml 引入。存档变量及设置值不变。

## 验证与限制

Lua 5.1 语法及运行回归覆盖 11 种语言 × 原生/EUI 两种样式；包括加载回退、推荐链接、套装来源、符文名称映射、紧凑排版、宝石补载、附魔星号、装备交换和帧复用。真实数据回归覆盖全部 80 组数据。

测试采用模拟客户端 API，不能替代游戏内字体、长文本宽度和实际数据缓存的视觉检查。重新加载后，检查 `/ifeui` 设置页、角色侧栏、观察目标、推荐装备悬浮提示、宝石附魔和宝典名称。英文长标签与俄语旧译文仍需实际客户端检查。

尚未具备完整俄语及其他欧洲语言/韩语的插件文字译文。地下城手册接口返回空值时，来源可能使用数据库中的英文名称；符文两个客户端 ID 都无法解析时，仍使用采集名称。`/ifeuitraits` 属于开发诊断，其聊天输出仍主要是中文。这些回退不会改变装备排名或附魔匹配结果。

本次检查对应版本 2.3.0，发布包包含新的语言文件。维护者的源码、客户端备份和采集工具只在本地保存，不随仓库或发布包分发。
